## 📌 About

**Star Rating** is a lightweight frontend UI component built with **HTML5, CSS3, and JavaScript**.  
It visually represents a rating system that lets users choose a value using stars — a common feature in reviews, feedback, and product ratings.

This project is great for practicing DOM manipulation and styling interactive elements in JavaScript. :contentReference[oaicite:1]{index=1}


## 🚀 Features

✨ What this project includes:

- ⭐ Interactive star rating UI  
- 🎨 Hover & click effects  
- 🖼️ Clean and simple design  
- 🧠 Built with plain JavaScript — no libraries/frameworks
